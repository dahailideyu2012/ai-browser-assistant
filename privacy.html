我们如何处理你的数据

1. 我们收集什么

我们（开发者）不收集、不存储、不上传你的任何个人数据。

本扩展在本地处理所有数据：

  • API Key / Base URL / 模型名：仅保存在你浏览器的 chrome.storage.local（本地），绝不上传到任何第三方服务器。
  • 网页正文、选中文本、截图：仅在你本地处理，除「发送给你自己配置的大模型服务商 / ima 知识库」外，不会上传给开发者。
  • 知识库内容：本扩展不再使用本地 IndexedDB 存储。知识库功能由腾讯 ima 提供——你在设置中自行启用并填写 ima 的 Client ID / API Key 后，保存的资料与检索请求会由浏览器后台直接发送到 ima 开放接口（ima.qq.com），存入你自己的 ima 账号。未启用该功能时，不会产生任何 ima 相关请求。
  • 端侧 AI（Prompt / Translator API）：在支持该能力的浏览器上，总结/翻译等推理完全在本地完成，零云端成本、零外传。

2. 数据如何发送给大模型

当你发起分析/总结/转写时，扩展会把所请求的网页内容（正文/图片/视频帧/音频）通过浏览器后台 Service Worker 发送给你在设置中自行填写的大模型服务商端点（OpenAI Compatible 网关）。

  • 发送目标完全由你配置（默认 https://api.openai.com/v1，可改为任意兼容端点）。
  • 除「你主动提交的内容」与「你的 API Key（用于鉴权）」外，不附带任何额外个人信息。
  • 开发者无法看到、也无法拦截这些内容——请求直接由你的浏览器发往你选择的服务商。

3. 权限说明

  • storage：保存你的配置（仅本地）。
  • activeTab / tabs / scripting：在你主动触发时读取当前标签页正文、列标签页、注入分析 UI、对当前页截图。
  • sidePanel：提供侧边栏沉浸式面板。
  • tabCapture：仅在侧边栏「音频转写」功能中，录制当前标签页音频并提交给你配置的 Whisper 端点。
  • contextMenus：右键菜单快捷入口。
  • host_permissions: <all_urls>：用于向各网站注入划词/视频分析 UI，以及向你的 API 端点发起请求（规避网页 CSP/CORS）。

我们只在我们明确需要时才访问数据，且绝不在后台静默收集。

4. 第三方服务

本扩展本身不内置任何第三方追踪/统计 SDK。你选择的大模型服务商受其各自隐私政策约束，请自行查阅。

5. 你的权利

数据全部存于你本地，你可通过「设置 → 清除」或卸载扩展随时删除。我们无从访问，故无法代你删除。

6. 联系方式

如对本政策有疑问：sdjy@ai-tokens.cn

English

How we handle your data

1. What we collect

We (the developer) do not collect, store, or upload any of your personal data.

Everything is processed locally in your browser:

  • API Key / Base URL / model name: stored only in your browser's chrome.storage.local. Never uploaded to any third-party server.
  • Page text, selected text, screenshots: processed locally; never uploaded to the developer, except when sent to the model provider or the ima knowledge base you configured yourself.
  • Knowledge-base content: this extension no longer stores anything in local IndexedDB. The knowledge-base feature is provided by Tencent ima — once you enable it and enter your own ima Client ID / API Key, saved notes and search queries are sent from the browser background directly to the ima Open API (ima.qq.com) and stored in your own ima account. No ima request is made while the feature is disabled.
  • On-device AI (Prompt / Translator API): when your browser supports it, summarization/translation runs entirely on-device — zero cloud cost, zero transmission.

2. How data is sent to the model

When you start an analysis/summary/transcription, the extension sends the content you requested (page text / image / video frame / audio) through the background Service Worker to the model provider endpoint you configured yourself (OpenAI Compatible gateway).

  • The destination is fully controlled by you (default https://api.openai.com/v1, can be changed to any compatible endpoint).
  • Aside from "the content you submit" and "your API Key (for auth)", no extra personal information is attached.
  • The developer cannot see or intercept this content — requests go directly from your browser to the provider you chose.

3. Permissions

  • storage: save your config (local only).
  • activeTab / tabs / scripting: read the active tab's text, list tabs, inject the analysis UI, and capture the current page — only when you trigger it.
  • sidePanel: provide the side-panel immersive mode.
  • tabCapture: only used by the side-panel "audio transcription" feature to record the current tab's audio and send it to your configured Whisper endpoint.
  • contextMenus: right-click shortcut entries.
  • host_permissions: <all_urls>: inject selection/video UI into sites and call your API endpoint (bypassing page CSP/CORS).

We access data only when clearly needed, and never collect silently in the background.

4. Third-party services

The extension itself bundles no third-party tracking/analytics SDK. The model provider you choose is governed by its own privacy policy.

5. Your rights

All data lives on your device; delete it anytime via Settings → Clear, or by uninstalling. We cannot access it and therefore cannot delete it on your behalf.

6. Contact

Questions about this policy: sdjy@ai-tokens.cn
